## 2. Как пользоваться

- **Только отчёт (что есть / чего не хватает):**
  ```bash
  python3 scripts/expand_survival_minimum.py --steps steps.json --report
  ```

- **Добавить недостающие карточки (с бэкапом):**
  ```bash
  python3 scripts/expand_survival_minimum.py --steps steps.json --expand --backup
  ```

Добавляются только те пункты из чек-листа, которых ещё нет в steps (сравнение по нормализованному `ru`).

## 4. Полная аналитика по всем курсам и заполнение тонких уроков

**Скрипт:** `scripts/full_courses_analytics.py`

- **`--report`** — срез по **всем 41 курсу**: по каждому уроку число карточек (word+phrase+casual), помечаются уроки с &lt; 8 карточек («тонкие»). Итог по приложению.
- **`--fill-thin`** — для каждого такого «тонкого» урока карточки из пула (все существующие в steps) добавляются до минимума 8. Одна и та же карточка — не чаще чем в 2 уроках (правило из аудита).

**Результат (2026-03-08):**
- До заполнения: **112 тонких уроков** (в основном Волна course_e_*, Душа course_s_*, Долгожители course_long_*), всего обучаемых карточек **1976**.
- После `--fill-thin`: добавлено **244 карточки** в тонкие уроки по всем курсам; тонких уроков **0**, всего карточек **2220**.
- В **lessons.json** синхронизирован **card_count** с фактическим числом карточек в steps (обновлено 224 урока).

**Запуск:**
```bash
python3 scripts/full_courses_analytics.py --steps steps.json --report
python3 scripts/full_courses_analytics.py --steps steps.json --fill-thin --backup
```
