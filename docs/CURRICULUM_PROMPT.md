# Промпт для сбора учебной программы (курс → уроки → карточки)

Краткий бриф, чтобы при добавлении или доработке курсов не было дублей внутри курса и пустых уроков без карточек.

---

## 1. Уровень курса

- **Название курса** (как в приложении).
- **Цель курса** в одном предложении (например: «На рынке: числа, кило/штука, торг, названия фруктов»).
- **Целевая ситуация** (рынок, такси, кафе, долгожители, медицина и т.д.).

---

## 2. Уроки внутри курса

Для **каждого урока** указать:

| Поле | Что писать |
|------|------------|
| **Тема урока** | Одна тема на урок (например: «Числа 20–500», «Кило и штуки», «Фрукты: названия», «Торг: дорого/дешевле»). |
| **Новые слова/фразы** | Список **только для этого урока** — без повтора одних и тех же карточек в других уроках курса. |
| **Сколько карточек** | Цель: 8–12 карточек на урок (включая 1 tip при необходимости). |
| **Повторы между уроками** | Допустимы только осознанные (например «Спасибо» в сценке в конце) с **другим контекстом** или в диалоге. |

**Важно:**  
- В одном уроке — одна тема.  
- Слова/фразы не дублировать между уроками без добавленной ценности (другой tip, диалог, ситуация).  
- **В курсах не «База»** (Тайский для жизни, Волна, Душа и т.д.) — только **ситуативная лексика**. Не повторять базовые «спасибо», «пожалуйста», «здравствуйте», «как дела?», «до свидания» как отдельные карточки: их учат в Базе. Вместо них — ситуативные фразы: «Спасибо за проверку», «Спасибо за поездку», «Хорошей дороги» и т.д.

---

## 3. Формат карточки (для контент-редактора)

Для каждой карточки желательно иметь:

- **Русский** (как показываем пользователю).
- **Тайский** (тайская запись).
- **Транскрипция** — только кириллицей (не латиница), тон по спеце: → ровный, ↘ падающий и т.д.
- **Tip** (по желанию): мнемоника, контекст, «как сказать по-другому» — одна подсказка на урок или на 2–3 карточки.

---

## 4. Проверка перед добавлением в генераторы

- [ ] У каждого урока курса есть свой список слов/фраз (нет «одно и то же» во всех уроках).
- [ ] В курсе нет уроков без карточек (для каждого урока в `steps.json` есть stepset с `items`).
- [ ] Фрукты/продукты/числа: если тема «рынок», список фруктов не 5 штук на весь курс, а нормальный набор (10+ или разбивка по урокам).
- [ ] Повторы между курсами допустимы только с разным контекстом (см. CONTENT_AUDIT_AND_RECOMMENDATIONS.md).

---

## 5. Пример (Король рынка — как должно быть)

| Урок | Тема | Пример контента (без дублей между уроками) |
|------|------|--------------------------------------------|
| 1 | Числа 20–500 | 20, 30, 50, 100, 150, 200, 300, 500 (тай + транскрипция) |
| 2 | Кило / штука | Кило, Штука, Полкило, Две штуки, Один кило манго |
| 3 | Торг | Дорого, Дешевле можно?, Скидка, Давай 150 бат |
| 4 | Цены | 150 бат, 200 бат, Сколько всего?, Всё вместе |
| 5 | Фрукты | Манго, Папайя, Арбуз, Ананас, Кокос, Дуриан, Личи, Рамбутан, Помело, Мангостин, Спелый, Кило манго |
| 6 | Покупка | Сколько всего?, Вот держите, Пакет, Беру |
| 7 | Итоговая сценка | Короткие фразы + можно повторы из уроков 1–6 в виде диалога |

Так в каждом уроке своё «мясо», дублей внутри курса нет, карточек достаточно.

---

После заполнения такого брифа контент можно переносить в скрипты генерации (`generate_life_jsons.py`, `generate_long_jsons.py` и т.д.) и в `steps.json` (через эти скрипты).

---

## Проверка «База от Тайки» (пример)

| Критерий | Результат |
|----------|-----------|
| У каждого урока есть карточки | ✓ 40 уроков, 0 пустых |
| 8–12 карточек на урок | ✓ везде 8–11 |
| Дубли внутри курса | Есть осознанные: b_7 сценки (Здравствуйте, Спасибо в разных местах), b_4 «Десять» в l1 и l2 — ок по промпту |
| Транскрипция | Кириллица во всех карточках |
