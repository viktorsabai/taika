## Как пересчитать саммари

Из корня проекта:

```bash
python3 -c "
import json
from collections import defaultdict, Counter
with open('steps.json') as f: steps = json.load(f)
with open('lessons.json') as f: lessons = json.load(f)
with open('taika/Resourses/taika_basa_course.json') as f: courses = json.load(f)
print('Курсов:', len(courses))
print('Уроков:', sum(len(c['lessons']) for c in lessons['courses']))
print('Stepsets:', len(steps['stepsets']))
print('Карточек (items):', sum(len(s.get('items', [])) for s in steps['stepsets']))
"
```

course_e_1 "Понятный тайский"
Цель: говорить так, чтобы тайцы понимали с первого раза, без напряжения и "фаранг-акцента".
Задачи: ясность + мягкость, правильный ритм (не торопиться, не кричать), избегание резких конструкций, добавление частиц смягчения (ной, на, каа).
Итог: юзер выучит 7+ маркеров вежливости и 12+ примеров "как сказать мягче".
Примеры карточек, которые нужны:
"Можно попросить?" → "ขอหน่อยได้ไหม" (кхо ной дай май)
"Не торопись" → "ไม่ต้องรีบ" (май тонг рип)
"Я не понял, повтори пожалуйста" → "ไม่เข้าใจ พูดอีกทีหน่อย" (май кхау-джай, пхут ик тхи ной)
"Спасибо заранее" → "ขอบคุณล่วงหน้า" (кхоп-кхун луанг-на)
"Давай спокойно" → "ค่อยๆ นะ" (кхой-кхой на)


course_e_2 "Работа с тайцами"
Цель: ставить задачи, следить за статусом и поддерживать рабочий small talk так, чтобы всё делалось вовремя и без обид.
Задачи: мягкие просьбы, комплименты, напоминания, уточнения дедлайна, похвала за работу.
Итог: юзер выучит 8+ рабочих фраз + 15 комплиментов/мотиваций.
Примеры карточек:
"Можешь сделать до пятницы?" → "ทำเสร็จวันศุกร์ได้ไหม" (там сэт ван сук дай май)
"Отличная работа!" → "งานดีมากเลย" (нган ди мак лёй)
"Как статус проекта?" → "โปรเจกต์เป็นยังไงบ้าง" (про-джект пэн янг-нгай банг)
"Если сложно — скажи, помогу" → "ถ้ายากบอกนะ ช่วยได้" (тха яак бок на, чуай дай)
"Спасибо, что так быстро" → "ขอบคุณที่ทำเร็ว" (кхоп-кхун тхи там рэу)
"Давай обсудим детали" → "คุยรายละเอียดกันหน่อย" (кхуй раай-ла-иат ган ной)

course_e_5 "Коды Таиланда"
Цель: понять и использовать тайский культурный код, читать между строк.
Задачи: крэнг-джай (не ставить в неловкое положение), джай-йен (оставаться спокойным), сабай (расслабленность), "май пэн рай" как защита лица.
Итог: юзер выучит 5+ идиом + 15 фраз с объяснением скрытого смысла.
Примеры карточек:
"Джай-йен" → "ใจเย็น" (джай йен) — "Оставайся спокойным, не дави".
"Крэнг-джай" → "เกรงใจ" (крэнг-джай) — "Не хочу тебя напрягать, поэтому говорю обходно".
"Сабай ди" → "สบายดี" — не просто "хорошо", а "всё в гармонии".
"Май пэн рай" → "ไม่เป็นไร" — "Не хочу, чтобы ты чувствовал себя виноватым".
"Давай потом" → "เดี๋ยวค่อย" (диао кхой) — скрытое "нет, но мягко".


course_e_6 "Мягкий тайский твой"
Цель: перейти от "фаранг-резкого" стиля к мягкому, приятному тайскому звучанию.
Задачи: смягчение речи, выбор правильного тона, добавление маркеров (на, каа, кхрап, ной), снижение громкости, улыбка в голосе.
Итог: юзер выучит 10+ фраз "до/после" + 15 маркеров чувств.
Примеры карточек:
До: "Сделай быстрее!" → После: "ช่วยทำเร็วหน่อยได้ไหม" (чуай там рэу ной дай май)
До: "Нет!" → После: "ไม่เอานะคะ" (май ау на ка)
До: "Я занят" → После: "ยุ่งนิดหน่อยค่ะ" (юнг нит ной ка)
Маркер: "Ной" → "หน่อย" — смягчает любую просьбу.
Маркер: "На" → "นะ" — делает фразу дружелюбной и мягкой.

Задачи: лёгкий флирт, намёки, "сабай ди май ка?", "на-рак", "май яак", "пен а-рай ган".
Итог: 25+ фраз + 15 словаря (чувства, статус отношений).
Примеры карточек:
"Ты очень милый" → "น่ารักมากเลย" (на-рак мак лёй)
"Хочу провести вечер вместе" → "อยากใช้เวลาด้วยกันตอนเย็น" (яак чуай-вела дуай-ган тон-йен)
"Мне комфортно с тобой" → "อยู่กับเธอแล้วสบายใจ" (ю кап тхё лэ́эу сабай-джай)
"Не хочу торопиться" → "ไม่อยากรีบ" (май яак рип)
"Кто мы друг для друга?" → "เราเป็นอะไรกัน" (рау пэн а-рай ган)

course_long_7 "Тайский юмор, мемы, поп-культура"

Примеры карточек:
