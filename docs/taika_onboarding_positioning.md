# Taika onboarding positioning contract

## Positioning

Taika is a personal **кун кру** for self-learning. It does not replace the learner by translating everything or presenting a finished answer. It gives the learner a small next step, listens to the learner's own attempt, explains what happened, and offers a way to reinforce the same material until it becomes usable speech.

## First-seconds message

The first interaction should communicate this without a feature list:

> **Taika не переводит за тебя. Она помогает научиться говорить самому.**

The user should understand the promise through an action within the first moments: choose one useful phrase, hear it, try it, and see a concrete explanation of the voice result.

## Learning loop

`choose → hear → try → understand → reinforce → continue`

Each state has one primary gesture. The selected phrase remains the same object while it moves from a learning card to a listening state, a recording state and a feedback state. The user should feel that Taika is accompanying the attempt rather than presenting disconnected pages.

## Product breadth to reveal after proof

After the core loop is experienced, the onboarding reveals a compact, interactive map of continuation: Match, syllable assembly and Audio Recall for reinforcement; Speaker tone/word feedback for speech; courses and lessons for structure; words and phrases for a personal shelf; and Taika+ as optional depth rather than the opening gate.

## Motion voice

Taika's motion is calm, attentive and responsive. Typewriter text establishes the next prompt. Cards settle into the center with a physical spring. Audio and microphone states animate locally around the active object. Feedback reveals in small causal steps. A completed attempt gives a restrained haptic confirmation and opens the next useful action. Motion never moves the entire layout unpredictably, and reduced motion preserves the same information order without spatial transforms.

## Copy rules

Use short, direct, learner-facing copy. Prefer verbs and concrete outcomes: `Скажи сам`, `Услышь тон`, `Закрепи по слогам`, `Выбери свой путь`. Avoid generic feature labels, abstract AI claims, long explanations and sales copy before the learner has experienced the loop.
