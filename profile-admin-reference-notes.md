# Admin reference notes

Source: https://www.taikaa.online/admin

The useful visual language is not a decorative card carousel. It is an operating view built around one focus, one primary signal, and one next step. The dominant hero uses a compact eyebrow/context label, a strong headline, a short supporting sentence, an explicit large primary signal, a decision/status marker, and one clear action. Supporting metrics are arranged as compact secondary signals rather than competing calls to action.

The admin page uses restrained dark graphite surfaces, thin borders, small status pills, strong metric numerals, and limited semantic colors. The key product pattern to adapt to Profile is:

`one focus → one signal → one next step`

For mobile Profile, the banner should therefore include:

1. A readable context label.
2. A strong primary insight, not a vague title.
3. A compact graph or signal strip as visual proof.
4. One clearly visible primary CTA.
5. At most two secondary metadata values, never three competing buttons.

Avoid copying the admin dashboard literally; use its signal hierarchy and product language inside the Taika liquid-glass identity.
