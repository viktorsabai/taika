# Quality gate 10/10 для «На одной волне»

## Owner-level definition

PRO-курс считается **10/10**, если после прохождения конкретного урока русскоязычный житель Таиланда может выполнить обещанное действие в реальной ситуации, понимает, когда фраза уместна, умеет отреагировать на типичный ответ собеседника и не получает культурно или лингвистически опасного совета.

Количество карточек не является KPI. Карточка добавляется только тогда, когда без неё ломается сценарий, отсутствует важная ветка ответа, не объяснён регистр или пользователь не может перенести навык в жизнь.

## Five mandatory gates

| Gate | Вопрос | Pass condition |
|---|---|---|
| 1. Scenario utility | Что пользователь реально сделает? | Урок формулируется как observable action, а не как тема или список слов |
| 2. Usable language | Есть ли что сказать/услышать? | Основная масса карточек — естественные реплики или слова, которые нужны внутри сцены; meta-explanation уходит в tip |
| 3. Conversation completeness | Что будет после первой фразы? | В уроке есть минимум одна response branch или ясный следующий ход; финальный урок собирает полноценную micro-scene |
| 4. Context and safety | Когда это уместно? | Есть адресат, register, relationship/status context и safety/cultural caveat там, где он нужен |
| 5. Linguistic integrity | Можно ли это правильно произнести и понять? | RU↔Thai alignment, единая фонетика, стрелка у каждого слога, без недопустимых slash alternatives и ложных универсальных правил |

## Per-course completion condition

Курс можно рекомендовать к push только если все шесть уроков проходят пять gates, course promise совпадает с материалом, нет существенного дублирования с соседним E/Life-курсом, а последний урок даёт transfer scene. Если один урок не проходит safety или linguistic integrity, курс получает **NO-GO**, даже если остальные уроки хорошие.

## Productive card taxonomy

| Тип | Роль |
|---|---|
| Core phrase | То, что пользователь реально говорит или слышит |
| Contrast pair | Резко/мягко, нейтрально/casual, можно/нельзя |
| Response branch | Типичный ответ собеседника и следующий ход пользователя |
| Context card | Кому, где и с каким уровнем близости это говорить |
| Cultural tip | Объяснение кода или ограничения; не выдаётся за phrase |
| Scene card | Сборка нескольких ходов в порядок действия |

## Automatic NO-GO signals

Пустой outcome, stale card_count, meta-label без поясняющей роли, phonetic slash с несколькими вариантами в одной карточке, RU↔Thai semantic mismatch, универсальное утверждение о «тайцах» без caveat, отсутствие boundary/consent в чувствительной теме и финальный урок без реального dialogue flow.
