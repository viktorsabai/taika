# Финальные мокапы Taika — Dictionary Quick Drawer

## Frame 1 — Любой основной экран с доступным словарём

Показать экран Favorites в текущей Taika identity. В app header рядом с логотипом есть отдельная иконка словаря с badge `4`. Это не фильтр избранного и не часть Speaker. Справа на edge экрана видна тонкая pink/lilac dictionary tab с маленьким символом книги/списка, которую можно потянуть. Заголовок экрана — `Избранное`.

## Frame 2 — Right-side Dictionary Quick Drawer

Показать тот же экран, но справа поверх него выезжает rounded glass drawer на 84% ширины. Основной Favorites screen частично остаётся видимым слева. В drawer: `Мой словарь`, `Твои фразы для жизни в Таиланде`, `4 последние фразы`, три личные phrase cards с русским смыслом, русским transliteration с tone arrows и speaker buttons. Внизу — `Открыть весь словарь →`. Drawer закрывается крестиком или свайпом вправо.

## Frame 3 — Полный экран «Мой словарь»

Показать destination после CTA `Открыть весь словарь`. Это не modal и не маленькое окно. Полноценный экран с header `Мой словарь`, подзаголовком `Твои фразы для жизни в Таиланде`, поиском/фильтрами `Все`, `Последние`, `На повторение`, списком личных фраз и нижней navigation bar. В header есть back arrow, но нет лишней duplicate dictionary button.

## Frame 4 — Drawer поверх Home/Speaker без изменения Speaker

Показать, что drawer можно открыть поверх другого основного экрана, например Speaker, но сам Speaker остаётся неизменным сзади. Видим header shortcut `▤ 4`, drawer с последними личными фразами и CTA `Открыть весь словарь`. Не показывать новый Speaker flow, запись или изменение карточки Speaker.

## Exact visual constraints

Единая тёмная Taika identity: почти чёрный фон, graphite glass panels, белая и светло-серая типографика, только pink/lilac gradient accents, тонкое технологичное свечение. Русские подписи, без X/Twitter branding, без английского текста кроме Taika/Speaker, без Thai script, без лишних новых bottom tabs, без маленького нечитаемого overlay. Four separate vertical iPhone screen mockups, same visual system and same phrase-card component.
