# Thai for Life — native-aware methodology contract

Каждый курс должен обучать не теме, а завершённой ситуации для русскоязычного фаранга в Таиланде. Для каждой карточки проверяется: **кто говорит, кому, в какой момент, зачем, что могут ответить и какой следующий шаг**.

| Course | Required scenario stages |
|---|---|
| L1 Police Stop | остановка → права/байк → шлем/пассажир → маршрут → repair → штраф/квитанция → exit/passport branch |
| L2 Taxi | точка → цена/метр → маршрут → correction/stop → wait/change → payment/receipt → Grab/night branch |
| L3 Market | item → unit/weight → quantity → price → soft bargain → accept/refuse → total/bag/payment |
| L4 Food | dish → spice → ingredients/allergy → add/remove → foodcourt pickup → taste/issue → bill/payment |
| L5 Pharmacy/Clinic | symptom → location/severity → medicine question → dosage/timing → allergy/contraindication → red flag → clinic |
| L6 Hotel | booking/check-in → room/key → amenities → maintenance → early/late check-in/out → bill/payment → checkout |
| L7 Beach | place/shade → chair/price → drinks → water flags/current → snorkel equipment → rescue/symptom → bill/exit |
| L8 Shop | find item → floor/stock → shelf price/promo → cashier/queue → bag/payment/receipt → exchange/return |
| L9 Emergency | immediate help → service → location/contact → symptom/event → wait/instructions → arrival/hand-off |
| L10 Gym | membership/trial → schedule → equipment/safety → trainer → locker/shower → pain/stop → exit/payment |
| L11 Festivals | festival context → permission/participation → respectful behavior → photo/boundary → exit/transport |
| L12 Salon | photo/request → length/shape → service/time/price → check result → correction → payment/rebook |
| L13 Housing | incident → location/evidence → urgency → owner/technician → access/time → result/follow-up → neighbor branch |
| L14 Delivery | order → condo address → track/status → courier meeting → fee/payment → inspect package → delay/damage/support |
| L15 Nightlife | order/water → price/bill → social approach → consent/boundary → refusal → transport/safe exit |

## Automatic red flags

Meta cards such as «от входа до выхода», «мягко в чате», «король рынка» and abstract nouns that cannot be used in a real utterance receive a review flag. A completed course must also contain at least one concrete repair/safety/exit branch where the situation requires it. Structural validators do not replace this semantic review.
